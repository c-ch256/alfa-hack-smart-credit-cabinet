# Тест-сценарии (D3)

Как проверять:
- **API по HTTP** — `python docs/product/smoke_scenarios.py http://localhost:8000` на свежей базе с демо-данными (выход 0 — всё прошло);
- **Автотесты** — колонка «Автотест»: рекомендуемые автотесты для Backend; имена — из прототипа backend, на котором сценарии проверены;
- **UI** — вручную на собранном фронтенде (после готовности экранов), по шагам из колонки «Шаги».

Пароль демо-учёток — `alfa-demo-2026`. Приоритет: **P1** — блокирует демо, **P2** — важно для оценки, **P3** — желательно.
