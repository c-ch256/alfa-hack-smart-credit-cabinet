# Тест-сценарии

Как проверять:
- **API** — `python docs/product/smoke_scenarios.py http://127.0.0.1:8000 <DEMO_PASSWORD>` на свежей базе с демо-данными (колонка «Smoke»);
- **Интерфейс** — по шагам ниже: `http://localhost:8080` после `docker compose up --build` (или `http://localhost:5173` при разработке);
- **Автотесты** — `pytest` в `backend/` команды.

Цифры — при `KEY_RATE=14`, маржах +4 / +3 (П2), скорере `mock`. Приоритет: **P1** — блокирует демо, **P2** — важно, **P3** — желательно.
