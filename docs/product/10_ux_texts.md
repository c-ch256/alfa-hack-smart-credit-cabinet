# UX-тексты (D2) — для Frontend (`src/lib/statuses.ts`)

Тон: на «вы», спокойно, коротко, без банковского жаргона. В клиентской части не используем слова «скоринг», «PD», «стоп-фактор», «аннуитет», «DSCR», «оффер».
Суммы — `Intl.NumberFormat('ru-RU')` + « ₽», даты — ДД.ММ.ГГГГ ЧЧ:ММ. `{…}` — подстановки из API.

### Причины → «Что можно сделать»

Тексты причин приходят из API (`decision_reasons`); фронт подбирает подсказку по ключевым словам. Слова «стоп-фактор», «PD», «скоринг» в причинах не используются.

| Причина (из API) | Что можно сделать |
|---|---|
| Бизнес не имеет статуса «действующий» по данным ЕГРЮЛ/ЕГРИП | Проверьте статус компании в ЕГРЮЛ/ЕГРИП. Если статус изменится, подайте заявку снова. |
| Просрочка по кредитам более 90 дней за последний год | Погасите просрочку. Мы сможем рассмотреть заявку после того, как кредитная история улучшится. |
| В кредитной истории есть невозвращённый кредит | Проверьте кредитную историю в БКИ. Если в ней ошибка — оспорьте её, затем подайте заявку снова. |
| Сейчас мы не можем предложить кредит: нагрузка на денежный поток или кредитный риск выше допустимых | Попробуйте меньшую сумму или больший срок — подбор покажет комфортный платёж. Когда снизится текущая долговая нагрузка, шансы вырастут. |
| Комментарий специалиста: {комментарий} | Если остались вопросы — подайте новую заявку с комментарием, специалист увидит его. |

## 9. Ошибки валидации (у поля)

Фронт дублирует проверки бэка (zod) и показывает те же тексты. При ответе 422 — текст из `errors[].message` у поля `errors[].field`.

| Поле | Условие | Текст |
|---|---|---|
| Сумма | пусто | Укажите сумму кредита |
| Сумма | не целое / буквы | Введите сумму цифрами, в целых рублях |
| Сумма | вне лимитов | Сумма должна быть от {min} ₽ до {max} ₽ |
| Срок | пусто | Укажите срок в месяцах |
| Срок | вне лимитов | Срок должен быть от {min} до {max} мес. |
| Цель | не выбрана | Выберите цель кредита из списка |
| Комментарий | > 2000 симв. | Сократите комментарий до 2000 символов |
| Объект инвестиций | пусто (инвест.) | Укажите, что приобретаете и у кого |
| Залог | пусто при сумме ≥ 5 млн ₽ | Для суммы от 5 000 000 ₽ укажите вид и стоимость залога |
| Стоимость залога | ≤ 0 | Укажите оценочную стоимость в рублях |
| Код подписи | не 6 цифр | Код состоит из 6 цифр |
| Комментарий сотрудника | < 3 симв. | Обоснуйте решение — клиент увидит этот комментарий |
