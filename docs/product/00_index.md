# Продуктовая документация — Product / UX / BA

Владелец: Product/UX/BA. Если разработчики хотят изменить контракт (поля, статусы, правила), решение принимает аналитик и фиксирует его здесь.

Документы описывают продукт команды в состоянии на **26.10.2026** (финальная версия `main`): реальные экраны, тексты, маршруты API и цифры. Проверка — [smoke_scenarios.py](smoke_scenarios.py) (25/25) и прохождение сценариев в интерфейсе.
